## 🚀 Featured Projects

<details>
<summary><b>⚽ Match Scanner — Value Bet Finder</b></summary>

<br/>

A **Next.js 14 (App Router)** football match scanner that fuses live odds with league standings to surface statistical-mismatch value bets in real time — engineered to run entirely on free-tier APIs.

| Aspect | Detail |
| :--- | :--- |
| **Stack** | Next.js 14, React, Tailwind CSS, lucide-react, isomorphic strategy engine |
| **Scale** | 9 European + South American leagues, ~36 fixtures/scan, multi-provider data fusion |
| **Performance** | Server-side caching (300s TTL), provider switching, credit-aware scan batching |
| **Security** | Site-wide HTTP Basic Auth middleware, per-IP rate limiting (429), server-only API keys |
| **Impact** | Surfaces value matches from free APIs (The Odds API + Football-Data.org) with zero recurring cost |
| **Repository** | [github.com/user247-2023/match-scanner](https://github.com/user247-2023/match-scanner) |

Built a null-safe `evaluateMatch` strategy engine combining statistical mismatch signals (goal-difference gaps, underdog form) with odds thresholds. Includes a mock-data mode, off-season empty states, GitHub Actions CI running `next build`, and one-click Vercel deploy.

</details>
